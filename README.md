# MiniAT v2

Thanks for purchasing a product from CoopersVE! This page covers connecting to your MiniAT's WiFi, managing its animations, and caring for it.

## Basics
- **Tap** the button once to cycle to the next animation.
- **Hold** the button down to view the network details for customisation.
- The MiniAT hosts its own WiFi network. Once connected, you can access its website to customise it.

## Default Network Details
| | |
|---|---|
| **WiFi name** | `MiniAT-XXXXXX` |
| **WiFi password** | Printed on the information sheet included with your MiniAT |
| **Website** | [miniat.local](http://miniat.local) |

The WiFi name and password can be changed to whatever you like under the **OTA** tab on the website.

## Adjusting Animations
1. Connect to your MiniAT's WiFi network and go to **miniat.local**. The website loads a bit slower than you're used to, so be patient.
2. Open **Manage Files**. Here you'll see all the files loaded on your MiniAT.
3. You can **delete**, **add** or **reorder** animations.
4. To delete an animation, hit the red **X**.
5. To add new animations, browse this repository. They're separated into categories so they're easy to find.
6. I recommend hitting the green **Code** button and choosing **Download ZIP** to get everything at once (it's easier to navigate).
7. Once you've found a file you like, upload it to the MiniAT.

## Custom Animations
The file manager accepts any image or GIF you find! The website downscales it to suit the MiniAT's display, with several options to help you get a good-quality result.

## Care
- The plastic is sensitive to heat and sunlight. Keep your MiniAT out of direct sunlight.
- Cycle to a new animation every so often, especially if you leave it on 24/7. This preserves the quality of the screen for longer.
